# Demo video media sources

The MandateGuard submission video uses only project-owned visuals, original
narration, and licensed sound effects.

## Project-owned material

- The narration script, MandateGuard wordmark treatment, diagrams, interface
  motion, and all on-screen copy were created for this project.
- Application screenshots and the live browser demonstration were captured
  from the MandateGuard public deterministic fixture.
- DataHub and MCP are referenced nominatively to describe the integration. No
  third-party brand logo is embedded.

## Voiceover

The English narration was synthesized locally with HyperFrames TTS using the
Kokoro `am_michael` voice. It contains no human recording or third-party
spoken-word sample.

## Sound effects

The video uses `chime`, `click`, `impact-bass-1`, `impact-bass-2`, `ping`,
`pop`, `typing`, and `whoosh-short` from the bundled HyperFrames `media-use`
sound-effect library. That library credits its effects to
[Pixabay Sound Effects](https://pixabay.com/sound-effects/) under the
[Pixabay Content License](https://pixabay.com/service/license-summary/).

## Music and stock media

No background music, stock footage, or third-party stock imagery is used.
